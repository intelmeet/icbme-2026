# Build fix — React Router server import

## Error fixed

The prerender script imported `StaticRouter` from `react-router-dom/server`. In the installed ESM package and Node.js 24, that subpath could not be resolved. It now imports from `react-router-dom/server.js`.

## What to do

1. Extract this project over a clean project folder.
2. Run `npm ci`.
3. Run `npm run build`.

The Browserslist/caniuse-lite message is a warning, not the cause of the failure. You can update it later with `npx update-browserslist-db@latest` when you have network access.

This change resolves the reported module-resolution error. A successful full build still depends on subsequent prerender and SEO audit steps passing in your local environment.
