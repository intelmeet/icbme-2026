# Build fix (2026-10-16, V4)

The V3 build failed because the browser bundle imported `react-helmet-async` as a default export, but version 2.0.5 exposes `Helmet` and `HelmetProvider` as named exports from its ESM entry.

Changes:
- Restored named ESM imports for `Helmet` in `src/seo/SEO.jsx`, `src/seo/SiteStructuredData.jsx`, and `src/seo/EventSchema.jsx`.
- Restored the named ESM import for `HelmetProvider` in `src/main.jsx`.
- In `scripts/prerender.mjs`, load `HelmetProvider` with Node's `createRequire()` so prerendering uses the package's CommonJS entry, avoiding Node's named-export interop failure when importing the package directly.

After extracting the ZIP on a machine with npm registry access, run:

```bash
npm ci
npm run build
```

The full install/build could not be executed in the packaging environment because `npm ci` timed out, so V4 has been statically checked but is not represented as a verified end-to-end build. If a build still fails, share the complete first error and stack trace.
